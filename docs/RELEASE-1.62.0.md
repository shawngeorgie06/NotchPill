# NotchPill 1.62.0

The notch now expands from its full hardware outline: both sides move outward as the bottom drops, with smooth, interruptible spring motion.

### Improvements

- Claude, Codex, and Cursor usage cards fit their summary, credits, and token details within the selected pill size without vertical scrolling.
- Larger, higher-contrast labels and metadata make small text easier to read on black surfaces.
- Refined card headings, spacing, picker controls, clipboard states, and CI metadata.
- Cleaner chip-to-card transitions, including a smooth return of collapsed chips.
- More reliable agent/session integration, usage toggles, terminal launching, process cancellation, media handling, and development builds.
- Safer update downloads validate release URLs and redirects before installation.

### Validation

930 tests passed locally, including expansion geometry, complete usage-card fitting, terminal reliability, updater safety, and visual fixtures for built-in, floating, and scaled displays.
